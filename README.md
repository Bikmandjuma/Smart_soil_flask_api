Rwanda Job Aggregator
About the Project
In Rwanda, many youths face challenges finding job opportunities due to the fragmented nature of job listings across different websites. This project addresses that problem by aggregating job postings from multiple job-seeking platforms used in Rwanda, allowing users to easily browse and apply for available positions in one place.

Problem
Many Rwandan youth spend time visiting different job-seeking sites only to find that some links are expired or the deadlines for application have passed. This project aims to streamline the job search process by:

Scraping job postings from popular Rwandan job sites.
Filtering out expired job opportunities.
Centralizing all active job listings on one platform.

Features
Job Aggregation: Collects job listings from multiple websites.
Up-to-date Listings: Only displays job postings that are currently open and valid.
Easy Navigation: Provides a user-friendly interface for job seekers to search and filter through available jobs.
No More Expired Links: Automatically removes expired job listings to avoid frustration when applying.

Technologies Used
Python: For web scraping and data handling.
Flask: To serve the web app and handle user interactions.
BeautifulSoup: For web scraping and extracting job details.
HTML/CSS/JavaScript: For the front-end interface.
Bootstrap: For responsive design.

How It Works
The platform scrapes job listings from major job-seeking platforms in Rwanda, such as JobInRwanda and Kora Job Portal.
It filters out expired job posts, ensuring only current job opportunities are displayed.
Users can easily search for jobs based on keywords, and the platform highlights matching job titles as they type.
Clicking a job title redirects users to the full job description and application instructions.

Installation and Setup

flask run
Access the app by navigating to http://localhost:5000 in your browser.
